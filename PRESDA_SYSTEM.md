# PRESDA SYSTEM

## CORE RULES

Always prioritize premium design, clean UI, excellent UX and modern web standards.

## DESIGN STYLE

* Premium news magazine aesthetic.
* Black background with red accents.
* Futuristic and cinematic feeling.
* Minimal but powerful design.
* Spacious layouts with strong visual hierarchy.
* Avoid clutter and unnecessary elements.

## BRANDING

* Official logo: Presda.
* Slogan: Your Daily Press.
* Keep branding consistent across all pages.
* Use the same logo proportions everywhere.
* Red accent color must remain consistent.

## UI / UX

* Think like a Senior UI Designer.
* Think like a Senior UX Designer.
* Every section must feel premium.
* Focus on readability.
* Focus on engagement.
* Improve user retention.

## MOBILE FIRST

* Mobile experience is the highest priority.
* All cards, images and text must be optimized for smartphones.
* No cropped faces.
* No hidden text.
* No overflow issues.
* Perfect responsive behavior.

## IMAGE RULES

* Faces must always be visible.
* Eyes should appear inside the safe area.
* Use smart focal point positioning.
* Avoid cutting heads, faces or important details.
* Optimize separately for desktop and mobile.
* Prefer object-position when necessary.

## FRAMER MOTION

* Use smooth premium animations.
* Use subtle hover effects.
* Use modern page transitions.
* Keep animations elegant and performant.

## IMPECCABLE QUALITY

* Every design decision must feel intentional.
* Improve layouts before implementing.
* Never accept average solutions.
* Seek the highest quality result possible.

## PERFORMANCE

* Fast loading.
* Optimized images.
* Clean code.
* SEO friendly.
* Accessibility friendly.

## PRESDA MISSION

Create the most premium independent digital magazine experience possible.

## ARTICLE IMAGE RULES

- Faces must always be fully visible.
- Never crop eyes, forehead or chin.
- The article image is more important than decorative backgrounds.
- Use object-fit: cover with smart focal points.
- Prioritize the subject over scenery.
- Mobile image composition is mandatory.
- Every article must have a separate mobile crop check.

## CONTENT RULES

- Articles must feel premium.
- Avoid generic AI-generated headlines.
- Headlines should be emotional, intriguing and professional.
- Focus on curiosity and storytelling.
- Every article should feel unique.

## PRESDA QUALITY STANDARD

If a design feels average, redesign it.
If a headline feels generic, rewrite it.
If an image crops a face, fix it.
If mobile experience is not perfect, improve it.
Always seek the highest quality version possible.
